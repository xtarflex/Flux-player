## 2026-05-16 - Prevent Path Traversal in Tauri Commands
**Vulnerability:** The `cache_tmdb_image` Tauri command accepted an `image_type` string from the frontend and directly interpolated it into a filesystem path (`app_dir.join("cache").join("images").join(image_type)`) without validation. Additionally, the `file_extension` extracted from the URL was neither sanitized nor size-limited before being used to construct the saved file name.
**Learning:** Even internal API inputs from a trusted frontend must be rigorously sanitized and allow-listed before being used in backend operations (especially those interacting with the filesystem). User inputs from external sources (like URLs) must be sanitized before being used to create local filenames.
**Prevention:** Implement explicit allow-lists for specific directory parameters (e.g. `image_type != "posters" && ...`). Sanitize dynamic string fragments (like file extensions) by enforcing character sets (`char::is_alphanumeric`) and length boundaries.
