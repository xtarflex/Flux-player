## 2024-05-19 - [CRITICAL] Prevent Path Traversal in Tauri Commands
**Vulnerability:** The `cache_tmdb_image` command in `src-tauri/src/commands/library.rs` accepted unvalidated strings for `image_type` and arbitrary file extensions extracted directly from user-supplied URLs. This permitted path traversal attacks, potentially allowing an attacker to write files into arbitrary directories outside the intended cache directory.
**Learning:** In a mixed environment where a frontend can pass direct arguments to backend Tauri commands, we must assume all inputs, especially file path segments and extensions, are potentially hostile. Blindly constructing paths with `app_dir.join()` using unvalidated external input enables directory traversal vulnerabilities.
**Prevention:** Always validate directory path segments against a strict allowlist (e.g., checking `image_type` against `["posters", "backdrops", "album-art"]`). Always sanitize dynamic components like file extensions (e.g., keeping only alphanumeric characters and truncating length) before appending them to a filename.
