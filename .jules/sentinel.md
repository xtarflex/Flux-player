## 2024-05-18 - Prevent Path Traversal in TMDB Image Caching
**Vulnerability:** The `cache_tmdb_image` command in `flux-player/src-tauri/src/commands/library.rs` used unsanitized user input (`image_type`) to construct a file path (`app_dir.join("cache").join("images").join(image_type)`). Furthermore, the `file_extension` was extracted from the URL and used without sanitization. This allowed an attacker to write files with arbitrary extensions to arbitrary directories.
**Learning:** Even when the primary purpose of a command is to cache files in a specific directory, user-provided inputs used to construct paths must be strictly validated. Relying on the client to provide valid subdirectory names or file extensions is dangerous.
**Prevention:** Always validate user-provided path segments against an allowlist (e.g., ensuring `image_type` is one of the expected values). Sanitize dynamically extracted file extensions by restricting allowed characters (e.g., alphanumeric only) and enforcing a maximum length.
