## 2026-05-07 - Path Traversal Vulnerability in `cache_tmdb_image`
**Vulnerability:** The `cache_tmdb_image` Tauri command accepted unsanitized user input for the `image_type` and `url` parameters, which was used directly to build a file path on the host system. This could lead to an arbitrary file write via path traversal.
**Learning:** By directly joining user-provided parameters to path directories (`app_dir.join("cache").join("images").join(image_type)`) and deriving extensions directly from unsanitized URLs, attackers could potentially inject `../` sequences or craft malicious file extensions to write files outside of the intended cache directory.
**Prevention:** Always validate path segments against a strict allowlist (e.g., matching exactly `"posters"`, `"backdrops"`, or `"album-art"`). Similarly, strictly sanitize dynamically generated pieces of paths, such as file extensions, ensuring they consist only of alphanumeric characters and have realistic length limitations. Use `.as_str()` matching and simple boolean validations for this sanitization.
