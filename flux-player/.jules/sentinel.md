## 2024-05-24 - Fix Path Traversal in Tauri IPC File Writes
**Vulnerability:** In `flux-player/src-tauri/src/commands/library.rs`, the `cache_tmdb_image` command received `image_type` and used it directly in path construction (`join(image_type)`). Further, the `url`'s file extension was parsed but unsanitized. This could allow an attacker to pass payloads like `../../../../etc/shadow` in `image_type` or inject a malicious file extension, risking path traversal attacks and arbitrary file creation in uncontrolled directories.
**Learning:** Tauri IPC arguments that dictate paths or filenames MUST be validated. Just because arguments come from the frontend does not make them inherently safe; they must be treated as untrusted input.
**Prevention:** Always use an allowlist approach (e.g., `["posters", "backdrops", "album-art"]`) when paths are determined by client parameters. Sanitize all extracted substrings, like extensions, validating their contents (e.g., alphanumeric) and lengths.
